# A/B Тестирование промптов для AI Meal Planner

Дата: 2025-11-19
Версия эксперимента: v1.0

## 1. Цель эксперимента

Проверить, какой вариант промптов (A или B) обеспечивает:

более точную генерацию недельного плана питания

более корректную генерацию замены блюда

более высокую структуру/качество контента согласно оценке LLM-судьи (GPT-4o-mini)

стабильное соответствие JSON-схеме WeekPlan / MealReplacement

### 2.2 Промпты для замены блюда

## 3. Методика эксперимента
3.1 Генерация (LLM)

Модель генератор: GPT-4o-mini

Формат вывода: response_format=json_schema

Две генерации:

WeekPlan по промптам A и B

MealReplacement по промптам A и B

3.2 Судейская оценка (LLM-as-a-judge)

Модель судья: GPT-4o-mini

Строгое структурированное оценивание (0–10) по критериям:

WeekPlan: goal_match, meal_type_correctness, calorie_match, preferences_respected, allergies_respected, diversity

MealReplacement: calorie_match, meal_type_match, preference_match, allergy_safety, similarity, quality

3.3 Метрика

Среднее арифметическое оценок по критериям

Побеждает промпт с наибольшим средним значением

## 5. Анализ результатов
### 5.1 PROMPT A стабильно превосходит PROMPT B

Это видно из обеих таблиц:

WeekPlan: A > B (+0.67)

MealReplacement: A > B (+0.67)

Разница одинакова и повторяется, что говорит о предсказуемом превосходстве A-версии.

## 6. Причины выигрыша PROMPT A
✔ Более чёткая структура требований

PROMPT A формулирует задачу прямолинейно, без “литературного описания”.

✔ Меньше вариативности

PROMPT B даёт модели больше свободы: “реалистичный”, “сбалансированный”, “не повторяться”
→ модель склонна к творчеству
→ judge оценивает такие ответы ниже по “strict оцениваемым критериям”.

✔ PROMPT A лучше следует JSON-схеме

Меньше отклонений от структуры → выше оценки всех критериев.

✔ PROMPT A лучше соблюдает BPЖУ и калорийность

Это отражено в calorie_match.

✔ PROMPT A лучше подходит под “LLM-as-a-judge”

Он ориентирован на функциональные требования, а не на эстетические.
