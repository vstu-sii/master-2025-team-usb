**Дата проведения тестов: 2025-12-01**

---

## 📌 Обзор документа

Этот документ описывает **два этапа оптимизации промптов** в рамках проекта *AI Meal Planner*:

1. **A/B тест** — сравнение исходного baseline-промпта A и улучшенной версии B.  
2. **A/B2 тест** — сравнение победителя (B) с новой продвинутой версией B2 (v3).

Цели тестирования:

- повышение точности JSON-схем,
- улучшение соответствия целевой калорийности,
- повышение реалистичности БЖУ,
- предотвращение повторов блюд,
- повышение логичности рецептов,
- улучшение итогового качества по оценке GPT-4o (6 критериев).

# 🧪 3. A/B2 тест для **замены блюда** (replace_meal)

## 📌 Итог: **качество A и B совпало полностью**

### Почему так произошло:

- исходный replace_A и replace_B **слишком похожи по структуре**,
- оба промпта дают модели одинаково мало инструкций,
- отсутствует строгая логика подбора блюда,
- оба промпта почти идентичны по поведению модели,
- минимальные стилистические различия не создают A/B различий.

### ✔ Вывод:  
Чтобы провести полноценный A/B тест по замене блюда, нужно создать **новый B2**, аналогично недельному плану (v3), с:

- многошаговым пайплайном,
- валидацией,
- проверкой аллергий,
- проверкой meal_type,
- структурой выбора блюда,
- логичностью блюд.

Этот промпт будет подготовлен как **replace_meal_v3**.
