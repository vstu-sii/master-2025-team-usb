## 2.2 Компонентная архитектура UI

### Основные принципы

- Реактивные компоненты, совместимые с React/Next.js.
- TailwindCSS + shadcn/ui (Card, Button, Tabs, Dialog).

## 2.3 Responsive Design

### Desktop (≥1024px)

- Триколоночная сетка на Dashboard (профиль, карточки, пресеты).
- Таблицы и карточки выровнены в грид.
- Sidebar фиксированный, контент центрируется.

### Mobile (≤768px)

- Вертикальный скролл.
- Карточки занимают всю ширину.
- Навигация свёрнута в “гамбургер”.
- Modal — полноэкранный overlay.

## 2.4 Состояния интерфейсов

| Состояние    | Пример                  | Реакция интерфейса                                 |
| ------------ | ----------------------- | -------------------------------------------------- |
| **Loading**  | При вызове API LLM      | Отображается `<Spinner />`, кнопки неактивны       |
| **Success**  | План успешно создан     | Появляется уведомление “План сгенерирован успешно” |
| **Error**    | Ошибка сети / валидации | Компонент `<Alert type="error" />` с сообщением    |
| **Empty**    | Нет данных              | Компонент `<EmptyState />` с CTA                   |
| **Disabled** | Невалидная форма        | Кнопка `disabled`, подсказки под полями            |
