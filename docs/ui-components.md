#### 1. Страница входа/регистрации

- **Layout:** Один столбец, контент по центру экрана.
- **Компоненты:**
  - `AuthCard`: Белая карточка с тенью.
    - `Logo`: Логотип приложения.
    - `Header`: Текст "Добро пожаловать в AI Meal Planner".
    - `GoogleAuthButton`: Большая кнопка с иконкой Google и текстом "Войти через Google".
- **Состояния:**
  - **Успех:** Перенаправление на главную страницу.
  - **Ошибка:** Появляется `Notification` (всплывающее уведомление) с текстом "Сервис Google временно недоступен. Попробуйте позже".

#### 2. Главная страница / Дашборд

- **Layout:** `Header` сверху, основная часть — сетка из карточек.
- **Компоненты:**
  - `AppHeader`: Навигационная панель с лого, ссылкой "Мои планы" и иконкой профиля пользователя.
  - `WelcomeMessage`: Приветствие "Привет, [email]!".
  - `PrimaryButton`: Кнопка "Создать новый план".
  - `PlanCard`: Карточка для отображения последнего плана или быстрого пресета. Включает заголовок (цель, калории) и дату.
- **Состояния:**
  - **Загрузка:** На месте карточки "Последний план" отображается `SkeletonLoader`.
  - **Пустое состояние (новый пользователь):** Секция "Последний план" скрыта.

#### 3. Форма генерации плана

- **Layout:** Форма по центру страницы.
- **Компоненты:**
  - `FormWrapper`: Контейнер для полей формы.
  - `SelectInput` для поля "Goal".
  - `NumberInput` для полей "Calories" и "Budget" с правилами валидации.
  - `TextArea` для "Preferences" и "Allergies".
  - `SubmitButton`: Кнопка "Сгенерировать".
- **Состояния:**
  - **Валидация:** При вводе некорректных данных (например, текст в поле "Калории") под полем появляется `ErrorMessage` красного цвета. Кнопка `SubmitButton` неактивна.
  - **Загрузка:** После нажатия на кнопку форма становится неактивной, и на кнопке появляется `Spinner`.

#### 4. Просмотр плана

- **Layout:** `Tabs` для переключения дней недели.
- **Компоненты:**
  - `TabGroup` и `TabPanel` (Пн, Вт, Ср...).
  - `MealCard`: Карточка для каждого приема пищи (Завтрак, Обед, Ужин). Содержит название блюда, КБЖУ, рецепт и кнопку "Заменить".
  - `PlanSummary`: Блок с общей информацией о плане (цель, калории).
  - `FloatingActionButton`: Кнопка "Список покупок".
- **Состояния:**
  - **Загрузка:** `SkeletonLoader` в виде карточек приемов пищи.
  - **Ошибка:** `ErrorMessage` с текстом "Не удалось загрузить план".

#### 5. Список сохраненных планов

- **Layout:** Сетка из карточек (`PlanCard`).
- **Компоненты:**
  - `FilterBar`: Выпадающие списки для фильтрации и сортировки.
  - `PlanCard`: Краткая информация о плане и кнопки "Открыть", "Удалить".
- **Состояния:**
  - **Пустое состояние:** `EmptyState` с текстом "У вас пока нет планов" и кнопкой `PrimaryButton` "Создать первый план!".

#### 6. Модальное окно замены блюда

- **Layout:** `Modal` поверх основного контента.
- **Компоненты:**
  - `ModalHeader`: "Замена блюда".
  - `DishInfo`: Информация о заменяемом блюде.
  - `TextInput`: Поле "Причина замены".
  - `AlternativeDishList`: Список из 3-5 предложенных вариантов.
- **Состояния:**
  - **Загрузка:** `Spinner` на месте списка альтернатив во время запроса к LLM.

#### 7. Список покупок

- **Layout:** Сгруппированный по категориям список.
- **Компоненты:**
  - `ShoppingListGroup`: Секция для категории (e.g., "Овощи") с заголовком.
  - `CheckableListItem`: Элемент списка с чекбоксом, названием продукта и количеством.
  - `SummaryBar`: Нижняя панель с общей стоимостью и кнопками экспорта.
- **Состояния:**
  - **Ошибка:** `Notification` с текстом "В этом плане нет данных об ингредиентах".
