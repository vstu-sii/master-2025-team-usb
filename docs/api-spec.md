# 4. API Спецификация — AI Meal Planner

---

## 4.1 Rate Limiting и защита API

| Тип пользователя | Лимит              | Период |
| ---------------- | ------------------ | ------ |
| Free             | 10 запросов к LLM  | день   |
| Premium          | 100 запросов к LLM | день   |

## 4.2 Пример запросов

**Создание плана**

```http
POST /plans

{
  "goal": "похудение",
  "calories": 1800,
  "budget": 1000,
  "preferences": "вегетарианская диета",
  "allergies": "орехи"
}
```

**Ответ**

```json
{
  "id": 14,
  "goal": "похудение",
  "calories": 1800,
  "budget": 1000,
  "total_days": 7,
  "created_at": "2025-10-27T10:50:00Z"
}
```
