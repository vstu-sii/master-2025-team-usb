#### Сценарий 1: Успешная генерация первого плана питания (Happy Path)

1.  **Вход:** Пользователь открывает сайт, нажимает "Войти через Google", успешно аутентифицируется и попадает на дашборд.
2.  **Инициация:** На дашборде он видит приветствие и большую кнопку "Создать новый план". Он нажимает на нее.
3.  **Заполнение формы:**
    - Выбирает цель: "Похудение".
    - Вводит калории: "1800".
    - Вводит бюджет: "5000".
    - В поле предпочтений пишет: "Больше рыбы и курицы, меньше красного мяса".
    - В поле аллергий пишет: "Арахис".
4.  **Генерация (Точка взаимодействия с LLM):**
    - Пользователь нажимает "Сгенерировать".
    - Кнопка становится неактивной, на ней появляется спиннер.
    - Система показывает сообщение: "Подбираем для вас идеальное меню... Это может занять до 30 секунд".
5.  **Просмотр результата:**
    - Через ~20 секунд пользователь перенаправляется на страницу просмотра плана.
    - По умолчанию открыта вкладка "Понедельник". Он видит 4 приема пищи с названиями, КБЖУ и рецептами.
    - **Микроинтеракция:** При наведении на блюдо карточка слегка увеличивается.
6.  **Сохранение:** Вверху страницы есть кнопка "Сохранить план". Пользователь нажимает ее, и появляется уведомление "План успешно сохранен!".

#### Сценарий 2: Замена блюда, которое не нравится (Edge Case)

1.  **Контекст:** Пользователь находится на странице просмотра сгенерированного плана. В меню на среду он видит "Тушеная капуста" на обед, но он ее не любит.
2.  **Инициация замены:**
    - Он нажимает кнопку "Заменить" на карточке "Тушеная капуста".
    - Появляется модальное окно.
3.  **Указание причины (Точка взаимодействия с LLM):**
    - В модальном окне он видит поле "Причина замены" и вводит: "Не люблю капусту, хочу что-то с курицей".
    - Нажимает "Подобрать альтернативы".
    - **Обратная связь:** На кнопке появляется спиннер.
4.  **Выбор альтернативы:**
    - Через 5-10 секунд LLM возвращает 3 варианта: "Куриная грудка на гриле с овощами", "Салат 'Цезарь' с курицей", "Куриный суп-лапша".
    - Напротив каждого варианта указаны КБЖУ.
    - Пользователь выбирает "Куриная грудка на гриле с овощами".
5.  **Обновление плана:**
    - Модальное окно закрывается.
    - На странице плана в обеде на среду теперь отображается новое блюдо.
    - **Микроинтеракция:** Общая калорийность за день и за неделю в шапке плана анимированно обновляется.
    - Появляется уведомление: "Блюдо заменено. План автоматически сохранен".

#### Сценарий 3: Ошибка при генерации плана (Ошибка)

1.  **Контекст:** Пользователь заполнил форму и нажал "Сгенерировать".
2.  **Сбой API (Точка взаимодействия с LLM):**
    - Система отправляет запрос к LLM, но API возвращает ошибку 503 (Сервис недоступен).
3.  **Обратная связь пользователю:**
    - Индикатор загрузки пропадает.
    - На странице появляется сообщение об ошибке: "К сожалению, не удалось сгенерировать план. Пожалуйста, попробуйте еще раз через минуту."
    - **Важно:** Все данные, введенные пользователем в форму, остаются на месте.
    - Кнопка "Сгенерировать" меняет текст на "Попробовать снова" и становится активной.
